┌─────────────────────────────────────────────────────────────────────────────┐
│                     PHYSICS: HOW IT WORKS                                    │
└─────────────────────────────────────────────────────────────────────────────┘

    EFT Reweighting Formula:
    ────────────────────────
    
    For event i in kinematic bin x:
    
              ┌──────────────────────────────────────────┐
              │   A(x_i, λ_target)      N_SM(x_i)        │
    w_i(λ) =  │  ───────────────────  × ──────────  × C  │
              │   A(x_i, λ_SM)         N_input(x_i)      │
              └──────────────────────────────────────────┘
    
    Where:
    • A(x, λ) = Σ a_n(x) × P_n(λ)  [EFT polynomial]
    • x = (mHH, |cosθ*|, pT_HH)    [kinematic variables]
    • λ = (kl, kt, c2, ...)         [EFT parameters]
    • N_SM(x) = # SM events in bin (from normalization files)
    • N_input(x) = # events in input sample
    • C = normalization to preserve total cross-section
    
    
    Why These Variables?
    ────────────────────
    
    ┌──────────────────────────────────────────────────┐
    │ gen_mHH           → Sensitive to resonances      │
    │                     and threshold effects         │
    │                                                   │
    │ gen_CosThetaStar  → Probes spin structure of     │
    │                     HH production                 │
    │                                                   │
    │ gen_pT_HH         → Sensitive to higher-order    │
    │                     corrections and pQCD effects  │
    └──────────────────────────────────────────────────┘
    
    These provide OPTIMAL discriminating power between different
    EFT scenarios while maintaining numerical stability!

┌─────────────────────────────────────────────────────────────────────────────┐
│                         TROUBLESHOOTING GUIDE                                │
└─────────────────────────────────────────────────────────────────────────────┘

    Problem: Missing gen-level variables
    ────────────────────────────────────
    Error: "KeyError: 'gen_mHH'"
    
    Solution:
    1. Check if variables exist: df.columns
    2. Add to tuple production (see SUMMARY.md Step 2)
    3. Or use add_gen_HH_variables.py for post-processing
    
    
    Problem: FileNotFoundError for coefficients
    ───────────────────────────────────────────
    Error: "FileNotFoundError: Coefficients_EFT/1D_mhh/..."
    
    Solution:
    1. Copy Coefficients_EFT/ from bbγγ repository
    2. Verify directory structure matches expected layout
    
    
    Problem: Weights are not ~1 for SM
    ──────────────────────────────────
    Symptom: weight_EFT_kl_1p00_... has mean >> 1 or << 1
    
    Likely causes:
    • Incorrect normalization files
    • Wrong cross-sections in config
    • Mismatch between input samples and normalization
    
    Solution:
    1. Regenerate normalization from RAW samples (no cuts!)
    2. Verify cross-sections in HEFT_points_out.yaml
    3. Check that same MC samples used for norm and reweighting
    
    
    Problem: Very large or very small weights
    ─────────────────────────────────────────
    Symptom: Some weights > 100 or < 0.01
    
    This can happen for:
    • Extreme EFT parameter values
    • Events in kinematic regions with poor statistics
    • Numerical instabilities
    
    Solutions:
    • Apply weight caps in your analysis
    • Remove extreme EFT points
    • Increase statistics in input samples
